# HMiMG - Vuetify Frontend

This is a refactored version of the HMiMG frontend using Vue 3 and Vuetify 3.

## Tech Stack
- Vue 3
- Vuetify 3 (Material Design)
- Vite
- Pinia (State Management)
- Vue Router
- Vue I18n
- Axios

## Getting Started

### Prerequisites
- Node.js 18+

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```
Runs the development server on [http://localhost:9110](http://localhost:9110).

### Build
```bash
npm run build
```
Generates production build in `dist/`.

## Configuration
Update `.env` file with your backend API URL:
```env
VITE_API_URL=http://localhost:9108/api
```
